# Ayush Manjilkar — Portfolio

A modern, responsive personal portfolio website built with HTML, CSS, and JavaScript. Features a dark theme with vibrant gradient accents, smooth animations, and mobile-friendly navigation.

![Portfolio Preview](preview.png)

---

## ✨ Features

- **Modern Dark UI** — Deep purple/cyan/rose gradient accents on a dark background
- **Typing Animation** — Dynamic role text in the hero section
- **Smooth Scroll & Active Nav** — Highlights the current section while scrolling
- **Mobile Responsive** — Hamburger menu and adaptive layouts for all screen sizes
- **Scroll Animations** — Cards and timeline items fade/slide in as you scroll
- **Back-to-Top Button** — Appears after scrolling down
- **Education Timeline** — Clean vertical timeline with hover effects
- **Skills Grid** — Categorized skill tags with hover interactions
- **Project Cards** — Feature list, tech stack badges, and action buttons
- **Contact Section** — Quick links for email, phone, location, GitHub & LinkedIn

---

## 🛠 Tech Stack

| Technology             | Purpose                                |
| ---------------------- | -------------------------------------- |
| HTML5                  | Structure                              |
| CSS3                   | Styling, animations, responsive design |
| JavaScript (Vanilla)   | Interactivity & animations             |
| Font Awesome 6         | Icons                                  |
| Google Fonts (Poppins) | Typography                             |

No frameworks or build tools required — just open and run.
